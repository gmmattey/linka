Política de Privacidade

Atualizada em 19 de setembro de 2026.

Esta política explica como o LagCheck trata informações ao medir a conexão no iPhone.

O que o app faz

O LagCheck mede a rota entre o iPhone e uma infraestrutura de referência para apresentar um resultado sobre a conexão naquele momento. A medição não comprova o ping de um jogo específico e não promete desempenho futuro.

Dados no aparelho

Os resultados e o histórico de medições ficam no seu iPhone. O app não exige uma conta para funcionar. Você pode apagar os registros pelo próprio app, quando essa opção estiver disponível.

Tráfego de medição

Para fazer uma medição, o iPhone troca tráfego de rede com a infraestrutura de referência e com os serviços de rede necessários para esse teste. Como em qualquer conexão com um servidor, o endereço IP usado pela sua rede é tecnicamente necessário para que a resposta volte ao aparelho. O LagCheck não usa esse tráfego para criar uma conta de usuário.

Atendimento

Quando você nos envia um e-mail, recebemos as informações que você escolhe colocar na mensagem e usamos esse contato para responder ao pedido. Evite enviar senhas, códigos de acesso ou dados financeiros.

Fale sobre privacidade

Para dúvidas ou solicitações sobre esta política, escreva para privacidade@lagcheck.app. Para ajuda com o app, use suporte@lagcheck.app.
