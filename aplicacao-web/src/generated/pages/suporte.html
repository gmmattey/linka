Fale com a gente

Encontrou um problema, tem uma dúvida ou uma sugestão? Escreva para suporte@linka.app. Informe o modelo do aparelho e a versão do Linka para agilizar.

Como cancelo o Linka+?

Abra os Ajustes do iPhone, toque no seu nome, em Assinaturas, escolha o Linka+ e cancele. Você mantém o acesso até o fim do período pago.

Como restauro minha compra?

No app, use a opção de restaurar compras nos Ajustes, com o mesmo Apple ID usado na assinatura.

Como apago meus dados?

As medições do Histórico ficam no aparelho. Apague medições pelo app ou remova o app para retirar os dados locais. Consulte a Política de Privacidade para saber mais.
