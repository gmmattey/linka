# Theo Network Diagnostics

Para cada métrica, localize método, unidades, amostra, timeout, cancelamento, origem (LAN/WAN), incerteza e apresentação. Dados de `NWPathMonitor`, URLSession, CoreWLAN ou gateway têm escopos diferentes e não substituem medição ausente. Jitter não prova Wi‑Fi; falha de upload/sonda não cria bufferbloat numérico; rede/rota não permite causa que a API não mede.

Exija falha fechada, linguagem proporcional e testes adversos: offline, troca de rede, background, resposta inválida, parcial e cancelamento. Retorne fatos, inferências e indisponibilidades separadamente.
