# Linka

SpeedTest para iPhone, iPad e Mac. O site é institucional, não uma versão web do teste.

- [Produto](documentacao/PRODUTO.md): capacidades, jornada, design e decisões.
- [Arquitetura](documentacao/ARQUITETURA.md): módulos, contratos e limites técnicos.
- [Operação](documentacao/OPERACAO.md): validar, usar simuladores, preparar release e materiais de loja.
- [Governança](documentacao/GOVERNANCA.md): responsabilidades e forma de trabalhar.

Código do app em `aplicativo-ios/`; site em `aplicacao-web/`. GitHub Actions desativado; validação e release são locais no Mac. Licença em [LICENSE](LICENSE).
