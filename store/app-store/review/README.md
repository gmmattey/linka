## Texto de base

O Linka mede a conexão por ação da pessoa. O fluxo de medição não exige conta Linka. O histórico guarda resultados; recursos adicionais dependem do acesso disponível no app.

No iPhone/iPad, os detalhes avançados de Wi-Fi usam uma integração com Atalhos configurada pela pessoa. No Mac, os dados disponíveis dependem das APIs e permissões do sistema.
